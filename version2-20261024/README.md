# Coursework Version 2 — AI-guided galaxy portfolio

Seven static pages share a responsive navigation, galaxy background, editorial typography and interactive engineering demonstrations. Open index.html through a static web server. All navigation is relative and supports GitHub Pages project hosting.

The student guided the visual and interaction design. Vehicle tasks are illustrative browser demonstrations; they do not establish measured physical vehicle performance. Personal Reflection and Conclusions remain student-only work.

## Recorded physiological signals

The deployed site fetches the 120-second anonymous case 1 sample directly from the public VitalDB FHIR endpoint in assets/recording-source.js. The dataset itself is not included in the public repository or deployment. Source availability and browser connectivity are required; failures show an unavailable status. This is historical recorded data, not a live feed or model predictions. Waveforms are subsampled from 500 to 100 Hz for display and numeric missing samples are retained. The locally retained excerpt supports local development only and is excluded from publication.

Source: https://vitaldb.net/dataset/ — review its Data Use Agreement. Citation: Lee HC et al., VitalDB, a high-fidelity multi-parameter vital signs database in surgical patients, Scientific Data 9, 279 (2022), https://doi.org/10.1038/s41597-022-01411-5 .
